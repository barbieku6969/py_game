Snake

Dette er et enkelt Snake-spill laget i Python.

Funksjoner:
- Klassisk slange-spill med bevegelse og frukt.
- Ny frukt-type: banan som gir 3 lengde i stedet for vanlig eple som gir 1.
- Smart dødslogikk: en bombe beveger seg rundt, og hvis du treffer den er det game over.
- Poengsystem: du kan se hvor mange poeng du får i hver runde.

Slik spiller du:
1. Start spillet ved å kjøre `spill.py` med Python.
2. Bruk piltastene til å styre slangen.
3. Spis frukten for å vokse og få poeng.
4. Unngå å krasje i vegger, kroppen din og bomben.

Mål:
- få 100 poeng uten at slangen blir eksplodert

Utvikling:
- Spillet er under utvikling, og flere funksjoner kan legges til senere.
